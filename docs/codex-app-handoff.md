# 雪影 Z7PRO · Codex App 接手提示词

在 calfnai/lijiujia-z7pro-model 仓库同步 main 后，从本文件继续。先读 README.md、docs/roadmap.md 的 12 项清单、docs/conversation.md。当前一直是概念稿阶段，直到用户明确更新状态。已有 13 案和工作树，沿用项目。

## 第一优先：锁定现款面板

用户指出上一轮效果图的开放环框、小屏、旋钮、小圆键和木色扶手组合取自 Linear 概念稿，不能作为现款 Z7PRO 的面板依据。截图是错误示例。既有 Three.js 模型的 J 部件也是示意模型。不要从任一旧 AI 图复原现款。

先搜本机项目资料、原始产品图、厂商图和明确标注“雪影 Z7PRO”的商品资料。找一张能辨认显示区、按钮和扶手连接的面板图及同款整机图，记录型号、来源、视角和文件路径；优先采用用户或厂家的原始资料。取得后先给用户看“现款整机 + 面板局部 + 图源”。确认轮廓、屏幕和按键位置、扶手相对位置后锁定同一份几何；四种姿态、主案和支线均复用。若找不到足够清晰的同款图，把面板标“待实物参照”，先做机底、侧面和机构动作。原 PDF 的 P175–180 仅提供凌序造型语言，P107–118 提供风格参考。

## 第二步：交付能拖进度的整机模型

目标日常成交价 1999 元。沿用 450 × 1300 mm 有效跑带，全域平整跑面，下电机盖，现款面板交互。使用明确的材质、光照和浅凸纹表达真实家用产品。两条连续滑轨：爬坡 0–15°（H 架、单液压杆及轮子随动）；折叠 0–100%（交代立柱和扶手转动、折平与竖放的关系；区分收折和整机竖起）。竖放时跑板正面朝墙，机底朝外，软脚接地，轮子用于搬动。保留讨论模型/色块图原入口。检查 0%、中间值和终点，再发布链接。尺寸与机构轨迹为概念近似。

给每项一个固定编号，每个候选有自己的图、改动、待决定事项；用户选定后才把“初稿选择”填上。可用同一整机底图或侧剖底图。把图放到对应选项旁，整机风格与部件选择分开保存。

## 第四步：多巴胺支线

主案 Linear 凌序。另设潮流活力（黄橙钴蓝、短节奏凸筋）、有机亲和（薄荷珊瑚、圆润端盖）、几何模块（紫蓝青柠、分段方形端盖）。每条说明色彩落在哪个现有部件、造型改变了什么。此前生成图仅供颜色和侧面语言讨论，其中面板不合格。把可用局部归入 07/08，其余待补，不能据此把 01/03/09 标完成。优先呈现候选，不提前确定最终配色或量产成本。
