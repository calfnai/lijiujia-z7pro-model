## 当前方向

以用户评价“接近正确”的暖白圆角壳体继续深化。Ossby GEO 提供平阔主面、清楚节点与内侧深色退让；Braun Powerdrill 参考图提供柔和外缘、大内圆角与真实分件仍保持整体连贯的处理。两者融合到同一台凌序，不继续作为两款互斥外观。

本轮取消跑台左右小流线饰件、S形线及对应外观凹槽。两侧采用干净连续暖白长面，后墩弧面收口。功能开口、维护口、轮组、轴座与撑杆让位仍保留。

## 必须先分开的总成

| 建模对象 | 应保留的关系 | 外壳处理 |
| --- | --- | --- |
| 跑台基座 | 下端立柱轴的安装基准 | 长侧板不跨接活动立柱或抬升架 |
| 左右长立柱 | 相对跑台向后放倒 | 平阔外侧面、圆润窄边、内侧深色回边 |
| Y形头部／屏幕扶手总成 | 相对长立柱转动；头部折叠方向反过来 | 原横向切口是实质分件，两件分别建实体；圆角、黑边在各自零件处结束 |
| 原小扳机 | 沿用原触发件；保留触达、释放与回位空间 | 新渲染切口边缘的微凸仅表达位置预留，不能替代原小扳机坐标与形状 |
| 根部轴座／轴端盖 | 固定侧与活动侧各自归属明确 | 不用一块暖白壳跨接转轴两侧 |
| 抬升架／轮组／推杆 | 沿原轴运动、轮组接地 | 下盖板让出完整扫掠空间 |
| 线束及传力通道 | 上下关节运动、释放与重锁 | 在结构确认前留接口与空间，不虚构精密机构 |

头部与立柱之间的切口在用户本轮草图和既有凌序CAD截图中都可见。切口位置必须保留，但其二维线条不能直接当成准确铰轴。使用态两侧外形对齐；折叠时两件真实相对运动，不能只在融合实体上画沟槽。

## 外观细节

- 立柱：先建宽而平静的长向主面，再加柔和边缘；避免整个截面鼓成软管。
- Y形头：外侧保持完整平面，内角舒展；头部切口内外贯通，不用黑色饰条跨缝。
- 扶手：沿用R5已验收的四款材质及标准连接形态。新图以黑色细网格示例，不代表四款已二选一。金属与防滑材质直接切齐，不做渐变。
- 面板：屏幕可斜，屏幕承载构件尽量不斜；保留操作面及其上的红色安全件。两张指定屏幕原图完整、原比例并列，不擅选其一。
- 侧栏：连续薄感暖白面，取消小S形饰件和遗留凹槽；深色脚踏面沿真实装配边界收口。
- 后墩：弧面包收，留出滚筒调节与维护空间。
- 机底：镜面沿贴片路线，非玻璃；基材与成像效果待样品核对。插拔式电源留足插拔、弯线及收纳空间。
- CMF：暖白细哑光／柔缎外壳、炭黑细纹内件、已确认扶手材质。树脂、色号、纹理与反射率由样板确定；渲染不是材料采购规范。

该动画支持“下轴倒柱＋上端头部相对转动”的外部动作关系，不能证明内部采用哪种同步机构。未展示完整展开重锁、真实施力、阻尼、左右释放或防夹性能。“厂家将UOK方案移植到凌序”是用户转述的厂家计划，并非已完成成果。UOK银色件不能替换凌序已明确沿用的原小扳机；头部反方向折叠也继续有效。

Z7Pro原STEP内可核对到立柱固定销、压簧、固定轴、固定座、滚针轴承及拉绳／拉簧名称。现有局部证据足以继续研究原根部锁止，尚不能独立证明扳机到两侧锁销以及上下轴的完整传力链。

## 建模参数：先建字段，再填实测值

| 参数 | 应由何处确定 | 检查内容 |
| --- | --- | --- |
| 上下轴中心、轴向与轴距 | 原装配CAD＋厂家UOK适配图 | 不从切口照片或AI图反算 |
| 使用角、折平角及两轴函数关系 | 厂家运动定义／样机 | 头部反向；不沿用旧动画拟合角度 |
| 扳机坐标、有效行程、操作力、回位 | 原件测量＋厂家定义 | 手指净空、释放保持、重锁确认 |
| 锁销啮合、限位与双侧同步 | 剖视、BOM、实际机构 | 不能将滚针轴承视为锁止齿盘 |
| 切口缝宽、壳厚、内外圆角 | 结构包络＋样板／工艺 | 使用对齐，运动时不碰壳、不跨缝 |
| 线束弯曲半径与余量 | 真实线束规格与完整动作 | 防拉扯、防夹线、可维护 |
| 扶手握持尺寸与扳机可达区 | 已确认外观＋人体／原件校核 | 显细不能靠侵占握持空间 |
| 折平厚度、宽度与托架包络 | 同一完整装配测量 | 屏幕／扶手／跑带／侧栏／尾部干涉 |
| 抬升与竖放支承点 | 真实支撑机构与工程验证 | 抬升目标工作面15°，轮组接地；竖放稳定性另核 |

用户附Z7Pro标示尺寸：使用态1470×720×1180毫米，折平1456×750×192毫米；原图提示人工测量有误差。这些是原机参照，不能直接当凌序升级版尺寸、公差或包装目标。旧研究角度、12毫米提销等演示参数不进入本轮制造参数。

## 同一模型需输出的视图

1. 使用态：正侧、前后3/4、上端切口、握把材质分界、下轴与侧栏端部。
2. 触发态：原小扳机可达区、有效行程、释放状态。
3. 运动中间态：上端反向运动与立柱后放的真实关系、各部件扫掠包络；先后及同步按厂家资料确定。
4. 折平态：头部与跑带、扶手与尾端、托架、线束和切口的最小间隙。
5. 展开重锁态：锁止啮合、两侧一致性、止挡和回位。
6. 抬升与竖放态：撑杆、轮组接地和机底贴片；稳定、承载与锁止仍需工程验证。
7. 外壳分解与CMF：各实体命名、装配归属、材料状态、装配缝与维护口。

新PNG仅是外观提议。轴位、圆角、缝宽、触发小片及轮廓比例均不作为测绘数据。厂家机构包未到前，可先完成分体外观与空间预留；内部机构保持待适配状态。
