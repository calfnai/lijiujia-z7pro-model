## 三款独立外观 · 用户本轮纠正优先

A「GEO＋Braun基础款」：平阔外框主面、黑色内侧退层、克制圆角及清楚分件。使用06图；大面不设浅碟凹区。

B「浅碟凹面款」：shallow dished surface / gently concave surface，大面积主面向内缓凹、连续边缘肩部与柔和过渡。原03、04、05图归入B，不再笼统称为GEO＋Braun款。

C「IBM复古款」：在A的框面与黑白层次基础上加入局部成组短凹坑。使用07图，暖灰细哑光壳体。直接纹样依据为用户卡带截图红框；IBM复古是用户命名。凹坑实底，不以此认定散热功能，数量、间距、深度尚未定型。

三款均保留为当前凌序外观分支，未选定其一；A与C为本轮新图，均待评审。此前“融合成唯一款式”的表述由本次三分支纠正覆盖。整机姿态、下置电机、无小S流线、平表头、圆角方形握把、分件与折叠要求共用；B图的浅凹曲面细节不自动用于A或C。

**表头采用平面壳体，使用态与扶手基本持平。** 此前向前上扬的表头鼻部不作为当前几何基准。屏幕角度与表头壳体角度分开：默认屏幕朝上、齐平；若结构允许且不破坏统一外观，可仅让屏幕模块小幅向用户翻起，不抬高或倾斜整块表头。手机支架本轮先不纳入；后续若加，通过机身前方开孔插入独立插件，不占用平整顶面。

**安全锁与安全绳连接点上移到表头朝向跑者的中央窄立面。** 以最新红框为准，位于黑色顶边下方的白色窄面；原底面红锁及其锁位取消，不保留上下两个安全件。**扶手是方形带圆角处理，不是圆柱。** 握持层、金属连接圈与端盖均采用同源圆角方形，保留方形平面与四角圆角。R5四款已确认材质和直接切齐分界继续有效，本轮几何修订不继承此前材质验收状态。最新标注原图与位置说明见评审页“红框就是新锁位”一节。

## 必须先分开的总成

| 建模对象 | 应保留的关系 | 外壳处理 |
| --- | --- | --- |
| 跑台基座／长外框 | 下端立柱轴的安装基准；外框与内侧功能层分别建实体 | 平阔主面、内侧黑色退层及明确端壳分缝；浅碟凹面仅B，局部短凹坑仅C；长侧板不跨接活动立柱或抬升架 |
| 左右长立柱 | 相对跑台向后放倒 | 平阔外侧面、圆润窄边、内侧深色回边 |
| Y形头部／屏幕扶手总成 | 相对长立柱转动；头部折叠方向反过来 | 原横向切口是实质分件，两件分别建实体；圆角、黑边在各自零件处结束 |
| 原小扳机 | 沿用原触发件；保留触达、释放与回位空间 | 新渲染切口边缘的微凸仅表达位置预留，不能替代原小扳机坐标与形状 |
| 安全锁 | 独立于原折叠小扳机，移至表头朝向跑者的中央窄立面 | 紧贴黑色顶边下方白色窄面；取消原底面锁位，留出插拔、拉脱、绳路与手部空间 |
| 握持层／金属连接圈／端盖 | 同源圆角方形截面，明确平面与四角圆角 | 不再做圆柱或圆形端帽；材质边界直接切齐，截面尺寸与圆角待CAD核验 |
| 屏幕模块 | 默认朝上齐平；可选仅屏幕小幅向用户翻起 | 不连带倾斜表头壳体，若破坏整体一致性则取消翻屏提议 |
| 根部轴座／轴端盖 | 固定侧与活动侧各自归属明确 | 不用一块暖白壳跨接转轴两侧 |
| 抬升架／轮组／推杆 | 沿原轴运动、轮组接地 | 下盖板让出完整扫掠空间 |
| 线束及传力通道 | 上下关节运动、释放与重锁 | 在结构确认前留接口与空间，不虚构精密机构 |

头部与立柱之间的切口在用户本轮草图和既有凌序CAD截图中都可见。切口位置必须保留，但其二维线条不能直接当成准确铰轴。使用态两侧外形对齐；折叠时两件真实相对运动，不能只在融合实体上画沟槽。

## 外观细节

- 立柱：先建宽而平静的长向主面，再加柔和边缘；避免整个截面鼓成软管。
- Y形头：表头壳体保持平面，与扶手基本持平，取消上扬鼻部；外侧主面平静、内角舒展。头部切口内外贯通，不用黑色饰条跨缝。
- 扶手：本轮按用户纠正改为圆角方形截面，有明确方形平面和四角圆角；握持层、金属连接圈、端盖同源，不再采用圆柱几何。R5已确认的四款材质与直接切齐分界继续有效；新图以黑色细网格示例，不代表四款已二选一。本轮几何和新图仍待评审，不能称已验收。
- 面板：默认屏幕朝上齐平；屏幕若可独立小幅向用户翻起，只转屏幕模块，不改表头壳体角度。若机构代价过大或破坏整体一致性，采用齐平方案。保留操作面。两张指定屏幕原图完整、原比例并列，不擅选其一。
- 手机支架：当前不加、不预设顶部立架；若后续需要，从机身前方开孔插入独立插件，不影响表头顶面平整、折平包络与海外运输。接口尺寸和固定方式仍待结构设计。
- 安全锁与折叠小扳机：分别建实体、分别命名。安全锁及安全绳连接点上移到朝向跑者的中央窄立面、黑色顶边下方白色区域；取消原底面锁位，不保留上下两个红锁。原小扳机仍承担既有折叠触发，不得将两者合并、换位或互相替代。安全锁的手部可达、拉脱方向、绳路及折叠净空由厂家核验。
- 侧栏与机身外框：建立平阔暖白主面，黑色脚踏／功能层在内侧真实后退，面宽与层差形成薄感；用克制圆角矩形、浅凹面和端壳台阶呼应Braun。取消小S形饰件及遗留凹槽，不新增镀铬装饰，不把普通白条当完整边框设计。浅凹深度、主面宽度、壁厚及圆角需CAD／工艺核对；外框不得跨接运动件。
- 后墩：弧面包收，留出滚筒调节与维护空间。
- 机底：镜面沿贴片路线，非玻璃；基材与成像效果待样品核对。插拔式电源留足插拔、弯线及收纳空间。
- CMF：暖白细哑光／柔缎外壳、炭黑细纹内件、已确认扶手材质。树脂、色号、纹理与反射率由样板确定；渲染不是材料采购规范。

## 建模参数：先建字段，再填实测值

| 参数 | 应由何处确定 | 检查内容 |
| --- | --- | --- |
| 上下轴中心、轴向与轴距 | 原装配CAD＋厂家UOK适配图 | 不从切口照片或AI图反算 |
| 使用角、折平角及两轴函数关系 | 厂家运动定义／样机 | 头部反向；不沿用旧动画拟合角度 |
| 扳机坐标、有效行程、操作力、回位 | 原件测量＋厂家定义 | 手指净空、释放保持、重锁确认 |

| 切口缝宽、壳厚、内外圆角 | 结构包络＋样板／工艺 | 使用对齐，运动时不碰壳、不跨缝 |
| 机身外框主面宽度、内退层差、浅凹面深度及端壳分缝 | 原结构包络＋本轮GEO／Braun造型方向＋工艺 | 层次来自真实实体；不侵占脚踏、撑杆、轴座与维护空间，不抄自行车机构 |
| 线束弯曲半径与余量 | 真实线束规格与完整动作 | 防拉扯、防夹线、可维护 |
| 圆角方形扶手宽高、四角半径及扳机可达区 | 本轮用户几何纠正＋人体／原件校核 | 握持层、连接圈、端盖同源；不以圆管替代，显细不能靠侵占握持空间 |
| 平表头顶面与扶手高度关系 | 本轮用户标注＋真实结构包络 | 基本持平，不以上扬壳体取得屏幕视角 |

| 安全锁安装面、拉脱方向与绳路 | 最新红框：朝跑者中央窄立面、黑色顶边下方＋厂家核验 | 取消原底面锁位；核对手部可达、绳路、折叠干涉，与原小扳机独立 |
| 折平厚度、宽度与可选前插插件包络 | 同一完整装配测量 | 屏幕／安全锁／扶手／跑带／侧栏／尾部干涉；支架先不纳入当前方案 |
| 抬升与竖放支承点 | 真实支撑机构与工程验证 | 抬升目标工作面15°，轮组接地；竖放稳定性另核 |

## 同一模型需输出的视图

1. 使用态：正侧、前后3/4、上端切口、握把材质分界、下轴与侧栏端部。用侧视确认平表头与扶手基本持平；补朝跑者视图，确认安全锁位于黑色顶边下方的中央白色窄立面、原底面无旧锁；补端视或截面，确认握持层、连接圈和端盖均为同源圆角方形。
2. 触发态：原小扳机可达区、有效行程、释放状态。
3. 运动中间态：上端反向运动与立柱后放的真实关系、各部件扫掠包络；先后及同步按厂家资料确定。
4. 折平态：头部与跑带、扶手与尾端、安全锁、线束和切口的最小间隙；以不带手机支架的平整表头检查运输包络。可选翻屏若研究，另给回平状态。
5. 展开重锁态：锁止啮合、两侧一致性、止挡和回位。
6. 抬升与竖放态：撑杆、轮组接地和机底贴片；稳定、承载与锁止仍需工程验证。
7. 外壳分解与CMF：各实体命名、装配归属、材料状态、装配缝与维护口；补机身边框节点视图，展示平阔主面、黑色内退层、浅凹面和真实端壳分缝，避免仅靠光影表达层次。

新PNG仅是外观提议。此前图中上扬表头、顶部手机支架、上操作面安全锁、底面下置红锁与圆柱握把均已由用户后续纠正覆盖，不能作为当前几何基准。此前平表头标注仅保留平整关系和屏幕可选倾角的依据，旧红框不再解释安全锁。轴位、圆角、缝宽、触发小片及轮廓比例均不作为测绘数据。厂家机构包未到前，可先完成分体外观与空间预留；内部机构保持待适配状态。
