## 11 月 3 日阶段判断

- **优先验证 11 永久固定梁端底座。** 算清端座向前伸多少、竖放时有效接地有多深、根部要多厚，再决定是否打样。04 的四个接触面可以与 11 组合。
- **保留独立的 180° 旋转脚座方案。** 用户确认的是动作与轴心：转轴穿过跑板外框主承力梁端面中心，脚座相对轴心有长短端。整只转半圈，长端从跑板正面侧换到底面侧。旧图里的翻脚动作已纠正。
- **首选收纳朝向为跑板正面靠墙、底部朝房间。** 收好扶手和表盘后，以实物检查墙距、实际接地点和重心。下沉电机盖、H 架与轮子都在机底。
- 原整机网页及研究页保留了探索历史。网页上的候选尺寸、旧落脚方式与概念渲染需要结合上述纠正记录阅读。固定版与旋转版均未取得实机验证。
